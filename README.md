# papyrus-mcp
MCP server plugin for Papyrus-Desktop 7.1. It lets AI bots read and edit the open model live,
and every edit can be undone.
- DESIGN.md: architecture, tool list, and roadmap
- INSTALL.md: install steps
- org.papyrus.mcp/: plugin source (build with build.sh)

**Guided workflow:** the server also ships MCP prompts and resources for an ICONIX + agile process, and a `workflow_status` tool that checks a model against it. See DESIGN.md §16 and INSTALL.md B2.
